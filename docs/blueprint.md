# **App Name**: CodeScan

## Core Features:

- QR Scan: QR Code Scanning: Use the device's camera to scan QR codes in real-time.
- Barcode Scan: Barcode Scanning: Scan various barcode formats using the device's camera.
- Custom Styles: Customizable UI:  Allow users to change the theme, color scheme, and fonts within the app to match their preferences.
- Scan Result: Result Display: Clearly display the scanned code's content on the screen.
- Copy: Copy to Clipboard:  Add a button to easily copy the scanned code to the clipboard.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5), reflecting reliability and focus.
- Background color: Light grayish-blue (#E8EAF6), offering a calm backdrop that prevents eye strain during prolonged use.
- Accent color: Vivid orange (#FF5722), providing clear visual cues to interactive elements in an otherwise monochrome design.
- Body and headline font: 'Inter', a sans-serif font known for its legibility, suitable for UI and scanned result displays.
- Use vector icons from a consistent set with a line-art style.
- Prioritize a clean, uncluttered layout that makes the scan results and interactive elements easily accessible.
- Employ subtle animations, such as a progress bar when processing scans.
